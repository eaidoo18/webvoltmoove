Questions

Is Voltmoove free?

Yes. Finding chargers is free for drivers. You only pay the charger operator for electricity.

Which plugs are supported?

CCS2, Type 2 and CHAdeMO, plus a filter for fast DC charging.

Can I run a charging station?

Yes. Station owners can list chargers, set prices and update status. Email us to get started.
